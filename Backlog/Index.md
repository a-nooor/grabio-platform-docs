## Rules

1. **Open.md** — only active items with owner, repo, and blocker/PR link
2. **No aspirational backlog** — if not scheduled, it does not go in Open.md
3. **Close item** → move to Done.md with date; remove from Open.md
4. **Session end** — sync Open.md before marking task done

- `#suba` — suba eco sys / Supabase
